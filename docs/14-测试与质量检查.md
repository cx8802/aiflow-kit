# 测试与质量检查

本项目第一版使用 Python 标准库 `unittest`，不引入额外测试依赖。

## 运行测试

```bat
cd /d D:\code_work\aiflow-kit
scripts\use-project-env.bat
set PYTHONPATH=D:\code_work\aiflow-kit\src
python -m unittest discover -s tests
```

## 基础编译检查

```bat
python -m compileall -q src tests
```

## CLI smoke test

```bat
python -m aiflow --help
python -m aiflow --version
```

## 临时目录端到端检查

```bat
set SMOKE=%TEMP%\aiflow-kit-smoke
if exist "%SMOKE%" rmdir /s /q "%SMOKE%"
mkdir "%SMOKE%"
cd /d "%SMOKE%"
D:\code_work\aiflow-kit\scripts\aiflow-dev.bat init
D:\code_work\aiflow-kit\scripts\aiflow-dev.bat doctor
D:\code_work\aiflow-kit\scripts\aiflow-dev.bat context
D:\code_work\aiflow-kit\scripts\aiflow-dev.bat plan smoke
D:\code_work\aiflow-kit\scripts\aiflow-dev.bat review
D:\code_work\aiflow-kit\scripts\aiflow-dev.bat verify --dry-run
D:\code_work\aiflow-kit\scripts\aiflow-dev.bat install-skills
```

## 当前覆盖范围

已覆盖：

- `init` 生成项目文件。
- `context` 生成文件扫描段落。
- `install-skills` 默认安装到项目 `.agents/skills`。
- `verify --dry-run` 只使用配置命令。
- `codex-user` 安装必须显式全局确认。
