# 快速安装

本项目提供 Windows CMD 脚本和 macOS / Linux shell 脚本。

Windows：

```bat
scripts\win\quick-install.bat
scripts\win\aiflow-env.bat
scripts\win\aiflow-install.bat
```

macOS / Linux：

```sh
scripts/mac/aiflow-dev.sh
scripts/mac/aiflow-env.sh
scripts/mac/aiflow-install.sh
scripts/mac/aiflow
scripts/mac/aiflow-install
```

平台脚本分开放在 `scripts/win/` 和 `scripts/mac/`，`scripts/` 根目录不放命令脚本。

## 安装 aiflow-kit 本身

项目级安装：

```bat
scripts\win\quick-install.bat
```

默认行为只影响 `aiflow-kit` 仓库本身：

1. 创建或复用 `aiflow-kit\.venv`。
2. 将 `packages\aiflow-cli` 以 editable 方式安装到这个 `.venv`。
3. 探测本机工具路径并写入 `.aiflow\env.local.toml`。
4. 安装前端设计与 Playwright 工具到 `aiflow-kit\.tools`。
5. 安装内置 Skills 到本仓库 `.agents\skills`。
6. 生成本地 Claude/Codex 插件包到 `.aiflow\dist`。
7. 验证 `scripts\win\aiflow-dev.bat --version` 可运行。

默认不会写入 `%USERPROFILE%\.agents\skills` 或 `%USERPROFILE%\.claude\skills`。

macOS / Linux 目前使用源码 shell 入口，不需要 PowerShell，也不会写全局 shell profile：

```sh
sh scripts/mac/aiflow-dev.sh --help
```

## 当前会话启用短命令

在一个 CMD 窗口里运行：

```bat
call F:\code_work\aiflow-kit\scripts\win\aiflow-env.bat
```

它会给当前 CMD 会话设置：

```text
AIFLOW_KIT=<aiflow-kit 路径>
AIFLOW_KIT_ROOT=<aiflow-kit 路径>
PATH=<aiflow-kit>\scripts;%PATH%
```

这个脚本只影响当前 CMD 窗口，不会用 `setx` 写永久用户环境变量。

在 macOS / Linux shell 中运行：

```sh
. /path/to/aiflow-kit/scripts/mac/aiflow-env.sh
```

它会给当前 shell 会话设置：

```text
AIFLOW_KIT=<aiflow-kit 路径>
AIFLOW_KIT_ROOT=<aiflow-kit 路径>
PATH=<aiflow-kit>/scripts:$PATH
```

同时定义当前 shell 内的 `aiflow` 和 `aiflow-install` 函数。这个脚本不会写 `~/.zshrc`、`~/.bashrc` 或 `launchctl setenv`。

## 在任意项目中一键安装

打开目标项目目录后运行：

```bat
cd /d <目标项目目录>
aiflow-install
```

macOS / Linux：

```sh
cd <目标项目目录>
aiflow-install
```

等价于项目级执行：

```bat
aiflow init
aiflow install-skills
aiflow env detect
aiflow context --compact
aiflow verify --auto --dry-run
```

如果目标项目已经有自己的 `AGENTS.md` 和 `CLAUDE.md`，只安装 `.aiflow` 和 `.agents/skills`：

```bat
aiflow-install --skip-rules
```

如果只想安装配置和 skills，暂时跳过上下文扫描：

```bat
aiflow-install --no-context
```

如果不想启用当前 shell 短命令，也可以直接运行：

```sh
sh /path/to/aiflow-kit/scripts/mac/aiflow-install.sh --skip-rules
```

## 显式全局 Skills

只有确认这些 Skills 已经足够通用时，才使用用户级安装：

```bat
scripts\win\quick-install.bat --global-skills
```

这个参数会额外写入：

```text
%USERPROFILE%\.agents\skills
%USERPROFILE%\.claude\skills
```

全局安装前仍应检查 Skills 中是否包含项目路径、项目命令、业务规则或一次性调试结论。

## 卸载旧的用户级内容

旧版本曾默认安装用户级 Skills。清理这些旧的用户级内容可以运行：

```bat
scripts\win\quick-uninstall.bat --dry-run
scripts\win\quick-uninstall.bat --yes
```

`quick-uninstall` 不会删除业务项目里的 `.aiflow/`、`AGENTS.md`、`CLAUDE.md` 或项目级 `.agents/skills/`。
