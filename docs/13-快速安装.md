# 快速安装

本项目提供一个快速安装脚本：

```bat
D:\code_work\aiflow-kit\scripts\quick-install.bat
```

它会执行七件事：

1. 探测本机 `aiflow-kit` 路径和工具环境。
2. 安装前端设计与 Playwright 工具到项目级 `.tools/`。
3. 安装通用 aiflow Skills 到 Codex 用户级目录。
4. 安装通用 aiflow Skills 到 Claude Code 用户级目录。
5. 生成 Claude Code 插件包。
6. 生成 Codex 插件包。
7. 验证源码版 CLI 可运行。

## 安装内容

Codex 用户级 Skills：

```text
%USERPROFILE%\.agents\skills\
├── aiflow-kit-guide\
├── aiflow-kit-installer\
├── project-analysis\
├── implementation-plan\
├── tdd-development\
├── frontend-design\
├── frontend-verify\
├── playwright-verify\
└── code-review-release\
```

Claude Code 用户级 Skills：

```text
%USERPROFILE%\.claude\skills\
├── aiflow-kit-guide\
├── aiflow-kit-installer\
├── aiflow-kit-updater\
├── project-analysis\
├── implementation-plan\
├── tdd-development\
├── frontend-design\
├── frontend-verify\
├── playwright-verify\
└── code-review-release\
```

项目级前端工具：

```text
.tools\
├── frontend-tools\
└── ms-playwright\
```

这些目录用于 `@playwright/test` 和浏览器缓存，属于运行时目录，不提交到 git。

Claude Code 插件包：

```text
D:\code_work\aiflow-kit\.aiflow\dist\claude\
├── .claude-plugin\plugin.json
└── skills\
```

Codex 插件包：

```text
D:\code_work\aiflow-kit\.aiflow\dist\codex\
├── .codex-plugin\plugin.json
└── skills\
```

## 不会做什么

快速安装不会：

- 修改系统环境变量。
- 执行 `setx`。
- 修改用户全局 `AGENTS.md` 或 `CLAUDE.md`。
- 把某个项目的 `.aiflow/config.toml` 写入全局。
- 写入项目业务规则、测试命令或风险路径。

## 运行后怎么用

当前会话临时使用 `aiflow` 命令：

```bat
set PATH=D:\code_work\aiflow-kit\scripts;%PATH%
aiflow --help
```

在某个项目中初始化：

```bat
cd /d D:\some-project
aiflow init
aiflow install-skills
```

Claude Code 本地测试插件包：

```bat
claude --plugin-dir D:\code_work\aiflow-kit\.aiflow\dist\claude
```

Codex 安装后建议重启，让它重新扫描 `%USERPROFILE%\.agents\skills`。

## 快速更新

在任意项目根目录中运行：

```bat
D:\code_work\aiflow-kit\scripts\aiflow-update.bat
```

它会更新全局 Codex Skills、全局 Claude Code Skills、Claude/Codex 插件包，以及当前项目的 `.agents/skills`、`.aiflow/context.md` 和 `.aiflow/context.compact.md`。
同时会检查并安装当前项目的前端设计与 Playwright 工具。
