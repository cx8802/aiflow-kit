# 快速安装

本项目提供一个项目级快速安装脚本：

```bat
scripts\quick-install.bat
```

默认行为只影响 `aiflow-kit` 仓库本身：

1. 创建或复用 `aiflow-kit\.venv`。
2. 将 `packages\aiflow-cli` 以 editable 方式安装到这个 `.venv`。
3. 探测本机工具路径并写入 `.aiflow\env.local.toml`。
4. 安装前端设计与 Playwright 工具到 `aiflow-kit\.tools`。
5. 安装内置 Skills 到本仓库 `.agents\skills`。
6. 生成本地 Claude/Codex 插件包到 `.aiflow\dist`。
7. 验证 `scripts\aiflow-dev.bat --version` 可运行。

默认不会写入 `%USERPROFILE%\.agents\skills` 或 `%USERPROFILE%\.claude\skills`，避免把还在演进中的项目能力污染到所有仓库。

## 显式全局 Skills

只有确认这些 Skills 已经足够通用时，才使用用户级安装：

```bat
scripts\quick-install.bat --global-skills
```

这个参数会额外写入：

```text
%USERPROFILE%\.agents\skills
%USERPROFILE%\.claude\skills
```

全局安装前仍应检查 Skills 中是否包含项目路径、项目命令、业务规则或一次性调试结论。

## 安装内容

项目级 Python CLI：

```text
<aiflow-kit>\.venv\
```

项目级 Skills：

```text
<aiflow-kit>\.agents\skills\
```

共享前端工具：

```text
<aiflow-kit>\.tools\frontend-tools\
<aiflow-kit>\.tools\ms-playwright\
```

本地插件包：

```text
<aiflow-kit>\.aiflow\dist\claude\
<aiflow-kit>\.aiflow\dist\codex\
```

这些目录属于本仓库运行时或生成物，不提交到 git。

## 使用

当前会话临时使用 `aiflow`：

```bat
set PATH=%AIFLOW_KIT%\scripts;%PATH%
aiflow --help
```

在业务项目中初始化：

```bat
cd /d <目标项目目录>
%AIFLOW_KIT%\scripts\aiflow-dev.bat init
%AIFLOW_KIT%\scripts\aiflow-dev.bat install-skills
%AIFLOW_KIT%\scripts\aiflow-dev.bat context --compact
```

或者先临时把脚本目录放入当前会话 PATH：

```bat
set PATH=%AIFLOW_KIT%\scripts;%PATH%
cd /d <目标项目目录>
aiflow init
aiflow install-skills
aiflow context --compact
```

## 更新

项目级更新：

```bat
%AIFLOW_KIT%\scripts\aiflow-update.bat
```

刷新某个目标项目的 `.aiflow` 文件和项目级 Skills：

```bat
cd /d <目标项目目录>
%AIFLOW_KIT%\scripts\aiflow-update.bat --with-project
```

显式刷新用户级 Skills：

```bat
%AIFLOW_KIT%\scripts\aiflow-update.bat --global-skills
```

## 卸载

旧版本曾默认安装用户级 Skills。清理这些旧的用户级内容可以运行：

```bat
scripts\quick-uninstall.bat --dry-run
scripts\quick-uninstall.bat --yes
```

`quick-uninstall` 不会删除业务项目里的 `.aiflow/`、`AGENTS.md`、`CLAUDE.md` 或项目级 `.agents/skills/`。
