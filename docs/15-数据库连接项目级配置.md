# 数据库连接项目级配置

`aiflow-kit` 支持把数据库连接信息保存到项目级配置中，让 Codex / Claude Code 在当前项目里知道应该连接哪些数据库。

安全原则：

- 非敏感连接信息写入 `.aiflow/databases.toml`。
- 密码、完整 DSN、用户名等 secret 只写入 `.aiflow/databases.local.toml`。
- `.aiflow/*.local.toml` 已加入 `.gitignore`，不应提交。
- 不把数据库连接写入用户全局配置。
- 不把某个项目的数据库配置安装成全局 Skill。

## 命令

```bat
aiflow db add
aiflow db list
aiflow db show
aiflow db test
```

## 添加 SQLite

```bat
aiflow db add local --type sqlite --path data\local.db
aiflow db list
aiflow db show local
aiflow db test local
```

写入：

```text
.aiflow/databases.toml
```

示例：

```toml
[databases.local]
type = "sqlite"
path = "data\\local.db"
```

## 添加 MySQL / PostgreSQL 等

推荐只保存非敏感信息和环境变量名：

```bat
aiflow db add dev-mysql --type mysql --host 127.0.0.1 --port 3306 --database app_dev --user-env APP_DB_USER --password-env APP_DB_PASSWORD
```

写入：

```toml
[databases.dev-mysql]
type = "mysql"
host = "127.0.0.1"
port = 3306
database = "app_dev"
user_env = "APP_DB_USER"
password_env = "APP_DB_PASSWORD"
```

## 会话里提供连接串

如果用户在会话里把 DSN 告诉 Codex / Claude Code，可以保存到项目级 local secret 文件：

```bat
aiflow db add dev --type postgres --dsn "postgres://user:password@127.0.0.1:5432/app" --secret-local
```

写入：

```text
.aiflow/databases.local.toml
```

这个文件被 `.gitignore` 忽略。

如果不加 `--secret-local`，CLI 会拒绝保存 secret。

## 查看配置

```bat
aiflow db list
aiflow db show dev
```

`show` 会隐藏 local secret：

```json
{
  "name": "dev",
  "type": "postgres",
  "dsn_local": "***"
}
```

## 测试连接

第一版只内置 SQLite 测试，因为 Python 标准库自带 `sqlite3`。

```bat
aiflow db test local
```

MySQL、PostgreSQL、SQL Server、Oracle、MongoDB 等数据库的测试需要项目选择对应客户端或驱动。第一版只保存连接配置，不默认安装数据库驱动。

## 给 Codex / Claude Code 的使用方式

当用户在会话里提供数据库信息时，agent 应该：

1. 判断是否包含 secret。
2. 非敏感信息写入 `.aiflow/databases.toml`。
3. secret 写入 `.aiflow/databases.local.toml`，必须使用 `--secret-local`。
4. 不写用户全局配置。
5. 不把数据库连接放入全局 Skills。

示例：

```bat
aiflow db add staging --type mysql --host 10.0.0.12 --port 3306 --database app --user-env STAGING_DB_USER --password-env STAGING_DB_PASSWORD
```

或者：

```bat
aiflow db add staging --type mysql --dsn "mysql://user:password@10.0.0.12:3306/app" --secret-local
```
