# 数据库连接项目级配置

`aiflow-kit` 支持把数据库连接保存为项目级 profile，让 Codex / Claude Code 在当前项目里知道可以访问哪些数据库。数据库配置属于项目事实，默认不写入用户全局配置，也不安装成全局 Skill。

## 安全边界

- 非敏感信息写入 `.aiflow/databases.toml`，例如类型、host、port、database、driver。
- 密码、完整 DSN、用户名等 secret 写入 `.aiflow/databases.local.toml`。
- `.aiflow/*.local.toml` 已加入 `.gitignore`，不要提交。
- 全局 Codex / Claude Skills 只知道如何使用 `aiflow`，不保存某个项目的数据库账号。
- 在会话里收到数据库账号时，优先保存到当前项目的 `.aiflow`，不要污染所有项目。

## 支持的数据库类型

当前 CLI 支持这些 profile 类型：

```text
sqlite, mysql, postgres, sqlserver, oracle, mongodb
```

`aiflow` 不把这些数据库驱动作为强制依赖。每个项目按需安装驱动到项目 `.venv`，这样不会污染全局 Python。

| 类型 | 推荐项目级 Python 驱动 | 说明 |
| --- | --- | --- |
| SQLite | Python 标准库 `sqlite3` | 不需要额外安装 |
| MySQL | `PyMySQL` | 纯 Python，适合项目级安装 |
| PostgreSQL | `psycopg[binary]` 或 `psycopg2-binary` | 推荐优先用 `psycopg` |
| SQL Server | `pyodbc` 或 `pymssql` | `pyodbc` 还需要系统已安装 ODBC Driver |
| Oracle | `oracledb` | 优先使用新驱动 |
| MongoDB | `pymongo` | `tables` 命令会列集合 |

## 项目级安装驱动

Windows 不使用 `.ps1`，统一用 BAT 激活项目环境：

```bat
scripts\use-project-env.bat
```

如果需要使用 `10808` 代理：

```bat
scripts\use-project-env.bat proxy
```

安装驱动示例：

```bat
scripts\use-project-env.bat proxy
python -m pip install PyMySQL
python -m pip install psycopg[binary]
python -m pip install pyodbc
python -m pip install pymongo
```

如果当前项目直接使用 `aiflow-kit` 源码或可编辑安装，也可以用 optional extras：

```bat
python -m pip install -e .[mysql]
python -m pip install -e .[postgres]
python -m pip install -e .[sqlserver]
python -m pip install -e .[oracle]
python -m pip install -e .[mongodb]
python -m pip install -e .[db]
```

这些依赖会安装到项目 `.venv`。如果当前项目没有 `.venv`，应先在项目内创建虚拟环境，仍然不要安装到系统 Python。

## 常用命令

```bat
aiflow db add <name> --type <type> ...
aiflow db list
aiflow db show <name>
aiflow db test <name>
aiflow db tables <name>
```

`show` 会隐藏 local secrets。`test` 会执行最小连接验证。`tables` 会列出表、集合或 SQLite 表。

## MySQL 示例

把非敏感连接信息写入项目配置，把账号密码写入 local secret：

```bat
aiflow db add zhihaoscm --type mysql --host 192.168.110.210 --port 3306 --database zhihaoscm --user root --password ****** --secret-local --force
aiflow db test zhihaoscm
aiflow db tables zhihaoscm
```

写入结果：

```text
.aiflow/databases.toml
.aiflow/databases.local.toml
```

## PostgreSQL 示例

使用环境变量名保存 secret 来源：

```bat
aiflow db add pg-dev --type postgres --host 127.0.0.1 --port 5432 --database app_dev --user-env APP_DB_USER --password-env APP_DB_PASSWORD
aiflow db test pg-dev
aiflow db tables pg-dev --schema public
```

或者把完整 DSN 保存到项目 local secret：

```bat
aiflow db add pg-dev --type postgres --dsn "postgresql://user:password@127.0.0.1:5432/app_dev" --secret-local --force
```

## SQL Server 示例

如果使用 `pyodbc`，系统需要先安装 SQL Server ODBC Driver，例如 `ODBC Driver 18 for SQL Server`。Python 包仍然安装到项目 `.venv`。

```bat
aiflow db add mssql-dev --type sqlserver --host 127.0.0.1 --port 1433 --database app_dev --driver "ODBC Driver 18 for SQL Server" --user-env MSSQL_USER --password-env MSSQL_PASSWORD
aiflow db test mssql-dev
aiflow db tables mssql-dev --schema dbo
```

如果使用完整 ODBC connection string，也可以放入 local secret：

```bat
aiflow db add mssql-dev --type sqlserver --dsn "DRIVER={ODBC Driver 18 for SQL Server};SERVER=127.0.0.1,1433;DATABASE=app_dev;UID=user;PWD=password;TrustServerCertificate=yes" --secret-local --force
```

## Oracle 示例

```bat
aiflow db add oracle-dev --type oracle --host 127.0.0.1 --port 1521 --database ORCLPDB1 --user-env ORACLE_USER --password-env ORACLE_PASSWORD
aiflow db test oracle-dev
aiflow db tables oracle-dev --schema APP_SCHEMA
```

## MongoDB 示例

```bat
aiflow db add mongo-dev --type mongodb --host 127.0.0.1 --port 27017 --database app_dev --user-env MONGO_USER --password-env MONGO_PASSWORD
aiflow db test mongo-dev
aiflow db tables mongo-dev
```

`aiflow db tables` 对 MongoDB 会列出 collection。如果没有配置 database，则列出可见 database。

## 给 Codex / Claude Code 的约定

当用户在会话里提供数据库连接信息时，agent 应该：

1. 判断哪些字段是 secret。
2. 非敏感信息写入 `.aiflow/databases.toml`。
3. secret 使用 `--secret-local` 写入 `.aiflow/databases.local.toml`。
4. 只在当前项目安装所需数据库驱动。
5. 需要联网下载依赖时，可使用 `scripts\use-project-env.bat proxy` 启用 `127.0.0.1:10808` 代理。
6. 不把项目数据库账号写入 Codex / Claude 全局配置。

## 当前实现能力

- `aiflow db add/list/show`：管理项目级数据库 profile。
- `aiflow db test`：支持 SQLite、MySQL、PostgreSQL、SQL Server、Oracle、MongoDB 的连接测试，前提是项目 `.venv` 已安装对应驱动。
- `aiflow db tables`：支持列出 SQLite 表、MySQL 表、PostgreSQL 表、SQL Server 表、Oracle 表、MongoDB 集合。
- 驱动缺失时，CLI 会给出项目级安装建议，而不是自动污染全局环境。
