# TDD Development

## Workflow

1. Find existing test style and nearby tests.
2. Add or update the smallest failing test or reproduction case.
3. Implement the smallest passing change.
4. Refactor while keeping behavior unchanged.
5. Run focused tests and record results.

## Output

- Test added or updated
- Implementation summary
- Verification result
- Remaining risk
