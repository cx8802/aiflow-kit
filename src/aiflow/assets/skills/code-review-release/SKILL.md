# Code Review Release

## Workflow

1. Run or read `aiflow review`.
2. Review findings by severity: bugs, tests, security, performance, compatibility, maintainability.
3. Run or read `aiflow verify`, or record why verification was not run.
4. Produce a concise delivery summary with risks and follow-ups.

## Output

- Findings
- Verification
- Risk
- PR summary
- Follow-up
