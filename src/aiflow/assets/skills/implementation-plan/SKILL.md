# Implementation Plan

## Workflow

1. Restate the goal and non-goals.
2. Identify impact scope and likely files.
3. Break work into 3-7 concrete steps.
4. List verification commands and acceptance criteria.
5. Ask for confirmation when high-risk areas are affected.

## Output

- Goal
- Non-goals
- Impact scope
- Steps
- Verification
- Risks
