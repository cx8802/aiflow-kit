# Frontend Verify

## Workflow

1. Identify framework, design system, and existing component patterns.
2. Implement the UI change with project conventions.
3. Start or request the configured dev server.
4. Verify desktop and mobile viewports.
5. Check overflow, empty states, loading states, error states, and key interactions.
6. Record screenshots or explain why screenshots were not produced.

## Output

- Viewports
- Checked flows
- Screenshots
- Issues found
- Verification commands
